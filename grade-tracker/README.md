# Student Grade Tracker

A simple command-line Python program that calculates weighted averages of **entered assignments**.

Run: `python grade_tracker.py` (Python 3.9+; no third-party libraries).

Enter a subject, assignment name, points earned, possible points, and relative weight. Enter a blank subject to see the summary.

For example, a score of 18/20 with weight 30 is worth 30 relative weight units. Weights are normalized across assignments already entered, so the answer is a **current average**, not a predicted final grade.
