# Study Habits Survey Analysis

Explore **synthetic survey responses** using Python, pandas, and Matplotlib. No real students were surveyed.

```bash
pip install -r requirements.txt
python survey_analysis.py
```

The program cleans numeric columns, excludes invalid rows, prints descriptive statistics, and generates `output/summary.txt`, `output/study_methods.png`, and `output/sleep_study.png`.

You can replace the CSV with your own anonymous, consensually collected data. A small convenience sample cannot establish cause and effect.
