# Library Borrowing Database (SQLite)

Practice linked relational tables, foreign keys, joins, grouping, filters, and date comparisons. Borrowers and book titles are fictional.

Run with the SQLite command-line tool:

```bash
sqlite3 library.db < library.sql
```

The script resets three sample tables on each run and prints five query results. It uses a fixed date, `2026-11-01`, for reproducible overdue examples. This is a teaching demonstration, not a production library system.
